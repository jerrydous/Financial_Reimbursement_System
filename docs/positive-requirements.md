# 生成代码的硬约束

实现 AI 在写每一个文件时同时满足：

1. 函数名用动词，类型名用名词，名字写完整词。公共函数有明确参数和返回类型。
2. 错误用类型化结果或 HTTP 异常，带稳定错误码。可预期业务分支必须带回稳定错误码。
3. 提前返回处理校验失败。核心路径保持一层主流程。
4. 输入在边界用 Zod 校验一次。领域函数假定进来的是已校验类型。
5. 一个函数只做一件事。超过一个事务边界就拆开，并说明哪个函数持有事务。
6. 注释只解释金额尾差、锁顺序、幂等和外部幂等键，不重复代码字面意思。
7. UI 状态来自服务端单据。前端可以暂存草稿，提交后以服务端状态为准。
8. 发票影像通过短时授权 URL 访问。API 不把对象存储密钥给浏览器。
9. 日志带 `documentId`、`workflowId`、`actorId`。不记录影像二进制和完整令牌。
10. 新依赖必须在说明里写明许可证、维护状态和它替换了哪段本可自研的代码。
